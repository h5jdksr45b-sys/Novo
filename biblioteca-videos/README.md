# Biblioteca de vídeos

Todos os vídeos do repositório, reunidos de várias branches e separados em três pastas.

- `prontos/`: versão final de cada peça, para postar ou anunciar. Subpastas: reels, anuncios-livro, protocolo-7-dias, consultorio, outros.
- `editados/`: versões intermediárias, alternativas e testes (sem trilha, sem narração, rascunhos, layouts).
- `crus/`: material bruto usado nas edições: falas gravadas, b-roll, clipes gerados e telas animadas.

`LINKS.txt` tem o link de cada arquivo, nessa mesma ordem.

Não há vídeo exportado do Reel Borderline mente (noir): só o material bruto está em `crus/borderline-mente-noir/`.
Projetos Remotion nunca exportados (Acalmar, Espelho, Imprevisto, Inteligência, Três Dicas, Reel Porta, Stories Respiração, Mito Rindo, Mito Apego) não entram aqui.
