# Ícones Protocolo 7 Dias

Traço branco 4px, um elemento vermelho #CC0000 por ícone, viewBox 96x96, fundo transparente.
Cada SVG tem `#base` (branco) e `#destaque` (vermelho) para animar separado no Remotion:
desenhar o `#base` com stroke-dashoffset (ex.: @remotion/paths evolvePath) e entrar o `#destaque` alguns frames depois.

| Arquivo | Uso |
|---|---|
| dia1-frase-fixa.svg | Frase fixa de presença |
| dia2-limite-sem-briga.svg | Limite sem briga |
| dia3-pausa-20min.svg | Pausa combinada de 20 minutos (arco vermelho = 20 de 60 min) |
| dia4-roteiro-pos-crise.svg | Roteiro de pós-crise |
| dia5-sair-dos-detalhes.svg | Sair dos detalhes no auge (lupa com menos = afastar o zoom) |
| dia6-previsibilidade.svg | Regra de previsibilidade (mesma marca em todos os dias) |
| dia7-autocuidado.svg | Autocuidado de quem cuida (bateria; animar o preenchimento crescendo) |
| extra-sinais-antes-da-crise.svg | Reconhecer sinais antes da crise |
| extra-dentro-de-casa.svg | O foco é o que acontece dentro de casa |

Fundos: gerados no Higgsfield, 9:16, 2k. Manter texto com margem de ~8% das bordas.
Paleta: #0D0D0D fundo, #CC0000 destaque, branco no texto. Archivo Black nos títulos, Poppins no corpo.
